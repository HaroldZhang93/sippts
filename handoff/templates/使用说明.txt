============================================================
  SIPPTS 离线交接包 · 使用说明
============================================================

【这是什么】
  一个自包含的离线交接包，内含：
    - env\base_env.zip          : 打包好的 Python 环境(conda base, 含全部依赖)
    - source\sippts\            : 项目源码
    - drivers\Wireshark-*.exe   : 抓包驱动安装包(Wireshark, 自带 Npcap)
    - 1-安装环境.bat / 2-运行GUI.bat / 3-打包EXE.bat : 一键脚本

  目标机器无需联网、无需预装 Python 或 Anaconda。

------------------------------------------------------------
【使用步骤】(目标机, 离线 Win10 x64)

  第 0 步：把整个『SIPPTS离线交接包』文件夹拷到本地硬盘。
           * 建议放在纯英文、无空格的路径，例如  D:\SIPPTS
           * 需要预留至少 15GB 磁盘空间(环境解压后约 10GB)。

  第 1 步：双击运行  1-安装环境.bat
           * 会解压 Python 环境(几分钟) -> 修复路径 -> 指向源码;
           * 最后弹出 Wireshark 安装向导，请用【管理员】完成安装，
             并务必勾选  "Install Npcap"(抓包/发包功能依赖)。

  第 2 步：双击运行  2-运行GUI.bat  ->  启动图形界面。

  第 3 步(可选)：双击运行  3-打包EXE.bat
           * 用 PyInstaller 重新打包出独立 exe，
             成品在  source\sippts\dist\  目录下。

------------------------------------------------------------
【常见问题】

  Q: 提示 "尚未安装 Python 环境"？
     A: 先运行 1-安装环境.bat。

  Q: 抓包 / arpspoof / rtphijack / sniff 功能报错找不到网卡或 tshark？
     A: 说明 Wireshark/Npcap 未装好。重新运行 Wireshark 安装包，
        安装时确保勾选 Install Npcap，装完重启一次电脑。

  Q: 能不能换个位置？
     A: 可以。整个文件夹是自包含的，移动后重新运行 1-安装环境.bat
        即可(脚本会按新位置重新指向源码)。

  Q: 中文乱码？
     A: 脚本已用 UTF-8(chcp 65001)。若仍乱码，右键 -> 以管理员运行，
        或在支持 UTF-8 的终端中执行。
